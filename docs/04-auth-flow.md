# 04. 가입·인증·로그인

## 가입 흐름
1. **가입**: 이름, 이메일, 비밀번호(8자 이상, 영문+숫자), 비밀번호 확인 입력 → 상태 `unverified`
2. **이메일 인증**: 6자리 코드를 메일로 발송(10분 유효, 5회 틀리면 잠김) → 맞으면 `pending`
3. **관리자 승인**: 인증을 마친 사람만 관리자 승인 목록에 나타난다. 관리자가 승인(`approved`) 또는 거절(`rejected`). 관리자에게 새 요청 알림 메일 발송, 승인되면 본인에게 메일 발송
4. **로그인**: 이메일+비밀번호. `approved` 만 통과. 상태별 안내 문구 제공

이메일 인증을 먼저 하는 이유: 남의 이메일로 요청이 오는 것을 걸러내기 위해서다.

## 비밀번호 초기화
이메일 입력 → 재설정 코드 발송 → 코드+새 비밀번호 입력 → 완료.
- 가입 여부와 상관없이 같은 응답을 준다.
- 변경하면 `tv`를 올려 **다른 기기의 로그인을 모두 무효화**한다.

## 보안 규칙
- 비밀번호는 argon2 해시로 저장, 인증 코드는 해시로 저장.
- 로그인·인증·재설정은 이메일별 10분에 5회 실패 시 잠시 차단.
- JWT 12시간. 관리자가 상태를 바꾸면 기존 토큰이 무효화된다.
- 이전 상태를 되돌릴 수 있다 (승인↔거절). 관리자 계정은 `.env`의 ADMIN_EMAIL/ADMIN_PASSWORD로 서버 시작 시 자동 생성.

## 서버 주소 설정
- 로그인 화면에서는 보이지 않는다. **관리자 화면의 "서버 설정"** 에서만 보고 수정한다.
- 로그인 전에는 누가 관리자인지 알 수 없으므로, 팀원 앱은 처음부터 서버 주소로 열리게 한다(서버가 화면까지 제공).
- IP → 도메인 전환 시 관리자가 새 주소를 팀원에게 알려 준다.

## 이메일 발송
- 테스트: SMTP 설정을 비우면 코드가 서버 콘솔에 출력된다.
- 운영: Gmail 앱 비밀번호 방식 (추후 SendGrid/Resend 등으로 교체 가능).
- 집 노트북에서 메일 서버를 직접 운영하지 않는다 (스팸 처리되기 쉬움).
