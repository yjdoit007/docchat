# 02. 전체 구조

## 구성도
```
[핸드폰/PC 웹앱(웹뷰)]
        │ HTTPS
        ▼
[공유기 포트포워딩 또는 터널] ──► [관리자 노트북 = 서버]
                                   ├─ Caddy (HTTPS, 리버스 프록시)  ← 외부 접속 단계에서 추가
                                   └─ FastAPI 서버 (server.py)
                                        ├─ 인증/승인 (관리자·Viewer)
                                        ├─ 문서 업로드·버전 관리
                                        ├─ 페이지 단위 검색
                                        ├─ LLM 호출(Ollama 로컬 또는 Claude API) → 근거 포함 답변
                                        ├─ SQLite (data/docchat.db)
                                        └─ 원본 PDF (data/files/문서ID/v버전.pdf)
```
웹앱 화면은 서버의 `static/` 폴더에 두면 같은 주소로 함께 제공된다 → 접속 주소가 하나.

## 질의응답 흐름 (RAG)
1. PDF 업로드 → 페이지별 텍스트 추출(PyMuPDF) → **조문(제N조) 단위 조각**으로 나눠 버전과 함께 저장
   - 모든 페이지에 반복되는 머리글(예: "법제처 1 국가법령정보센터")은 제거, 여러 쪽에 걸친 조문은 하나로 합침
   - `제4조의2` 같은 가지 조문과 부칙도 구분. 조문 구조가 없는 문서는 페이지 단위 조각
2. 질문 → 기준 버전 선택 (기본: 문서별 최신, `as_of` 날짜가 있으면 그 날짜까지 올라온 최신)
3. 선택된 버전의 조각 중 관련도 높은 상위 조문 검색 (기본: Ollama 4개, Claude 8개 / `.env`의 TOP_K). 조문 제목에 질문 단어가 있으면 가산점
4. 해당 조문만 LLM에 전달(개정 표시 제거, PDF 줄바꿈 이음), "소스 밖 추측 금지·인용문 그대로 복사" 규칙으로 JSON 답변 생성
5. 서버가 인용문이 실제 원문에 있는지 **검증**. 띄어쓰기·괄호 모양·가운뎃점·개정 표시 차이만 허용하고,
   화면에는 모델이 쓴 글이 아니라 **원문에서 잘라 온 구간**을 보여 준다. 근거 번호를 잘못 달았으면 다른 근거 조문에서 찾아 바로잡는다
6. 답변 + `verified`(확인된 인용 유무) + 출처(문서·버전·조문·페이지·인용) + 관련 조문 반환, 질문·답변은 로그에 저장

## 데이터 모델 (SQLite)
| 테이블 | 내용 |
|---|---|
| users | 이름, 이메일, 비밀번호 해시, role(admin/viewer), status(unverified/pending/approved/rejected), tv(로그인 무효화용) |
| codes | 이메일 인증·비밀번호 재설정 코드(해시, 만료, 시도 횟수) |
| documents | 문서 이름 |
| versions | 문서별 버전 번호, 업로드 시각(KST), 업로더, 파일 해시, 쪽수 |
| pages | 버전별 페이지 번호와 텍스트 (원문 보기용) |
| chunks | 버전별 검색 조각: 조문 이름(label), 시작·끝 페이지, 텍스트 |
| logs | 누가·언제·무엇을 물었고 어떤 답과 출처가 나갔는지 |

## 버전 관리 규칙
- 같은 문서 이름으로 올리면 v1 → v2 → v3 … 로 쌓인다. **이전 버전은 삭제하지 않는다** (증빙용).
- 같은 파일(해시 동일)을 최신 버전으로 또 올리면 거절한다.
- 답변마다 어느 버전을 근거로 했는지 출처에 표시한다.

## 기술 스택
| 영역 | 선택 |
|---|---|
| 서버 | Python 3.11+, FastAPI, SQLite |
| PDF | PyMuPDF (스캔 PDF는 OCR 후 업로드 필요) |
| LLM | `.env`의 `LLM_PROVIDER`로 전환. 기본 `ollama`(로컬·무료, 모델은 OLLAMA_MODEL, 기본 gemma3:4b) / `claude`(Claude API, 모델은 CLAUDE_MODEL) |
| 인증 | JWT(12시간), argon2 비밀번호 해시 |
| 메일 | SMTP (Gmail 앱 비밀번호) — 설정이 없으면 콘솔 출력(테스트용) |
| 클라이언트 | HTML/JS 웹앱, 웹뷰 호환, 흑/백 테마 |

## 검색 방식과 한계
- 현재: 조문 단위, 한글 2글자 조각 기반 BM25식 점수 + 조문 제목 가산. 형태소 분석 없이도 "지연이자를" ↔ "지연이자" 가 맞는다.
- 한계: 같은 뜻의 다른 표현은 못 찾을 수 있다.
- 확장 계획: 문서가 많아지거나 의미 검색이 필요해지면 임베딩(벡터) 검색을 추가하고 키워드 검색과 섞는다.
