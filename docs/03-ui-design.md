# 03. 화면 설계

## 시안 비교
| 시안 | 특징 | 어울리는 상황 |
|---|---|---|
| A+B 메신저+뷰어 | 말풍선 대화, 출처 칩, 모바일 하단 시트 | 핸드폰에서 자주 물어볼 때 |
| C 검색형 | 큰 검색창, 요약 답변+출처 카드, 후속 질문 칩 | 특정 문구를 빠르게 찾을 때 |
| D 3단 작업공간 | 문서 목록 / 대화 / 원문, 어두운 배경 | 노트북에서 문서를 대조할 때 |

## 최종 결정: A+B+D 통합
- 대화는 **말풍선(A+B)** 형태.
- 출처 버튼은 **D 방식**: 호박색 테두리 버튼(`약관 p.143`)을 누르면 눌린 상태로 채워지고 원문이 바뀐다.
- **원문은 새 창·시트 없이 답변 바로 아래에 펼친다.** 같은 버튼을 다시 누르면 접힌다. 근거 문장은 형광펜 표시.
- PC는 왼쪽 문서·버전 목록 + 대화의 2단. 목록에서 이전 버전(v2, v1)을 누르면 해당 버전 표시로 원문이 열린다.
- 상단에 **기준 버전 선택**(최신 / 특정 날짜 버전)과 **흑/백 테마 전환**. 테마는 기기 설정을 따르되 선택을 기억한다.

## 접속 화면
로그인 / 가입 / 이메일 인증 / 승인 대기 / 관리자 승인 / 비밀번호 찾기(코드 → 새 비밀번호 → 완료). 흐름은 `04-auth-flow.md` 참고.
- 입력 오류는 필드 바로 아래에 고칠 방법을 안내한다.
- 비밀번호 찾기 안내문은 "가입된 이메일이라면 코드를 보냈어요"로 써서 가입 여부를 드러내지 않는다.

## 문구 원칙
- 해요체, 능동형, 버튼은 하는 일을 그대로 쓴다 ("승인 요청 보내기", "비밀번호 변경").
- 화면 속 약관 문구는 확인용 샘플이며 실제 내용이 아니다.
