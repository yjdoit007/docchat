## 남은 작업
1. [ ] 서버 실행 테스트: 로그인 → PDF 업로드 → 질문 (README의 /docs 화면)
2. [ ] 실제 문서 몇 개로 검색 품질 확인 (못 찾는 질문이 있는지)
3. [ ] 웹앱 구현: 확정 시안을 서버 API와 연결 (`server\static\`)
4. [ ] 관리자 화면: 문서 업로드·버전 목록, 가입 승인, 서버 설정, 질문 로그
   - [ ] 관리자 여러 명: 승인된 사용자를 관리자로 지정/해제하는 API와 화면 (마지막 관리자는 해제 불가, 누가 지정했는지 기록)
5. [ ] 외부 접속: 포트포워딩 → DDNS 도메인 → HTTPS(Caddy) 또는 Cloudflare Tunnel
6. [ ] Gmail 앱 비밀번호 설정 후 실제 메일 발송 확인
7. [ ] (필요 시) 의미 검색(임베딩) 추가, 스캔 PDF OCR
8. [ ] 한글 문서 업로드 지원: 공공기관 문서는 PDF와 함께 HWP를 많이 쓴다. HWPML(법령정보센터 저장 형식, XML)·HWPX(XML 압축)·HWP(바이너리) 순으로 검토. 페이지 개념이 없으므로 출처를 "조문/문단" 단위로 표시하는 방안 필요
