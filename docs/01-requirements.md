# 01. 요구사항

## 배경
- 삼성화재 업무에서 사용하는 공용 문서가 여러 개이고, 문서 한 권이 300쪽 이상일 수 있다.
- 여러 사람이 특정 문구를 찾거나, 문서에 근거해 질의에 대한 답을 받아야 한다.
- 내 업무가 법적으로 문제없는지 **문서를 찾아 증명**해야 할 때가 있다. 문서를 기억하는 친구가 필요하다.

## 핵심 요구
1. 팀원 여러 명이 접속해도 **하나의 공통 문서 기준**으로 답을 받는다.
2. 답변에는 반드시 **출처(문서명·버전·페이지)와 원문 인용**이 붙는다. 문서에 없으면 "근거를 찾지 못했다"고 답한다.
3. 문서는 **날짜별·버전별로 보관**한다. 특정 날짜 기준 버전으로도 질문할 수 있다.
4. 사용자는 **관리자(본인)** 와 **Viewer(팀원)** 로 나눈다. 가입은 간단한 승인으로 처리한다.
5. 대화형으로 친절하게 답한다 (LLM 사용).

## 클라이언트
- 앱 형태이되 웹뷰 기반의 간단한 웹앱.
- 디자인은 여러 시안을 보고 고른다. 흑/백 테마 전환 지원.
- 서버 주소(IP 또는 도메인)로 접속한다.

## 서버 / 접속
- 클라이언트-서버 구조. 서버는 문서 저장, 버전 관리, 가입 승인, 질의응답을 담당한다.
- 처음에는 IP로 접속하고, 테스트 후 무료 도메인을 발급받아 전환한다.
- 집 공유기를 통해 밖에서 핸드폰으로 집 노트북(서버)에 접속한다.

## 가입 요구
- 앱을 처음 실행하면 가입(승인 요청) 화면이 나온다. 이름·이메일·비밀번호를 입력한다.
- **이메일 인증**을 거친 사람만 관리자에게 승인 요청이 전달된다.
- **비밀번호 초기화** 기능을 제공한다.
- 서버 주소 설정은 관리자에게만 보인다.
