# 06. 외부 접속 구성

## 목표
밖에서 핸드폰으로 집 공유기를 거쳐 노트북(서버)에 접속한다. 처음엔 IP, 테스트 후 무료 도메인.

## 기본 방식: 공유기 포트포워딩
1. 노트북에 고정 내부 IP 지정(공유기 DHCP 예약), 예: 192.168.0.10
2. 공유기에서 포트포워딩: 외부 포트 → 192.168.0.10:(서버 포트)
3. 노트북 방화벽은 해당 포트만 허용, 절전 모드 해제
4. 외부에서 `https://공인IP` 또는 도메인으로 접속

## 주의사항
- 가정용 공인 IP는 **바뀔 수 있다.** IP 접속은 테스트용으로만 쓰고 무료 도메인(DuckDNS, No-IP 등) + DDNS로 일찍 전환한다.
- **IP 직접 접속은 HTTPS 인증서를 받기 어렵다.** 로그인이 있으므로 도메인 전환 후 Caddy로 HTTPS를 자동 적용한다.
- 통신사가 CGNAT(공인 IP 미할당)이면 포트포워딩이 안 된다 → 아래 대안.
- 포트를 직접 여는 방식은 공격 대상이 된다. 로그인 시도 제한(구현됨), 최신 업데이트 유지.

## 더 안전한 대안
- **Cloudflare Tunnel**: 포트를 열지 않고 노트북이 바깥으로 연결. CGNAT·유동 IP 문제 해결, HTTPS 자동.
- **Tailscale**: 팀원 기기를 사설망으로 묶음. 외부 노출이 전혀 없지만 팀원 모두 앱 설치 필요.

## 서버 PC 운영 체크
- 노트북이 켜져 있고 절전하지 않아야 한다.
- `data\` 폴더(DB + 원본 PDF)를 정기 백업한다.
- 서버 주소가 바뀌면 관리자 화면 "서버 설정"에서 수정하고 팀원에게 안내한다.

## 상태
미착수. 서버 실행 확인 후 진행.
