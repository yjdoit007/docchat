# 문서 도우미 사용 안내

문서 도우미는 등록된 공용 문서(법령·약관·지침)를 근거로 질문에 답하는 챗봇이에요. 답변마다 근거가 된 문서·버전·조문과, 원문에서 그대로 가져온 인용문을 함께 보여 줘요.

## 문서 도우미란?
문서 도우미는 팀이 함께 쓰는 문서 챗봇이에요. 관리자가 올린 문서 안에서만 근거를 찾아 답하고, 문서에 없는 내용은 추측하지 않고 "근거를 찾지 못했어요"라고 답해요. 지금 등록된 문서는 풍수해ㆍ지진재해보험법, 같은 법 시행령, 같은 법 시행규칙이에요.

## 접속 주소
문서 도우미 접속 주소는 https://docchat.tail15f4b2.ts.net 이에요. 핸드폰과 PC 브라우저 어디서나 이 주소로 들어오면 돼요. 회사 밖이나 LTE에서도 접속할 수 있어요.

## 가입하는 방법
처음 쓰는 사람은 가입해야 해요. 가입은 네 단계예요.
1. 로그인 화면에서 "처음이신가요? 가입하기"를 눌러 이름, 이메일, 비밀번호를 입력해요. 비밀번호는 8자 이상, 영문과 숫자를 함께 써야 해요.
2. 입력한 이메일로 6자리 인증 코드가 와요. 코드는 10분 안에 입력해야 하고, 늦으면 "코드 다시 받기"를 누르면 돼요.
3. 인증이 끝나면 관리자에게 승인 요청이 가요. 관리자가 승인할 때까지 기다려요.
4. 승인되면 가입한 이메일과 비밀번호로 로그인해요.
인증 메일이 오지 않으면 스팸함을 확인하고, 그래도 없으면 관리자에게 알려 주세요.

## 로그인이 안 될 때
"관리자 승인을 기다리는 중이에요"가 나오면 아직 승인 전이에요. "이메일 인증을 먼저 끝내 주세요"가 나오면 가입 때 받은 인증 코드를 입력해야 해요. 비밀번호를 여러 번 틀리면 10분 동안 로그인이 막혀요. 10분 뒤에 다시 해 보세요.

## 비밀번호를 잊었을 때
로그인 화면에서 "비밀번호를 잊으셨나요?"를 누르고 가입한 이메일을 입력하면 재설정 코드가 메일로 와요. 코드와 새 비밀번호를 입력하면 바뀌어요. 비밀번호를 바꾸면 다른 기기에서 로그인한 상태는 자동으로 끝나니 다시 로그인하면 돼요.

## 앱으로 설치하기
문서 도우미는 핸드폰 홈 화면에 앱처럼 설치할 수 있어요. 앱 스토어는 필요 없어요.
- 안드로이드: 크롬으로 접속해 로그인한 뒤, 오른쪽 위 동그란 계정 버튼을 누르고 "앱으로 설치"를 눌러요. 버튼이 없으면 크롬 메뉴(⋮)에서 "앱 설치" 또는 "홈 화면에 추가"를 눌러요.
- 아이폰: Safari로 접속해 아래쪽 공유 버튼(네모에 위쪽 화살표)을 누르고 "홈 화면에 추가"를 눌러요. 다른 브라우저 앱에서는 이 메뉴가 없을 수 있어요.
설치하면 홈 화면의 문서 도우미 아이콘으로 주소창 없이 앱처럼 열려요.

## 질문하는 방법
화면 아래 입력창에 궁금한 것을 문장으로 쓰고 "보내기"를 누르면 돼요. 예를 들어 "풍수해보험의 보험목적물은 뭐예요?", "정부가 보험료를 얼마나 지원하나요?"처럼 물어보면 돼요. 문서에 쓰인 낱말(예: 보험목적물, 보험기간, 손해평가인)을 넣으면 근거를 더 잘 찾아요. 질문은 1,000자까지 쓸 수 있어요.

## 답변 모드 (빠름과 내부)
입력창 위에서 답변 모드를 고를 수 있어요.
- ⚡ 빠름 (Gemini): 보통 2~3초 안에 답해요. 질문과 근거 조문이 Google로 전송돼요.
- 🔒 내부 (로컬): 이 서버 안에서만 처리해요. 외부로 나가는 내용은 없지만 답이 나오기까지 20초 이상 걸려요.
빠름 모드가 사용량 한도에 걸리거나 응답하지 않으면 자동으로 내부 모드로 답하고, 답변 아래에 그 사실을 알려 줘요. 고른 모드는 다음 접속 때도 기억해요.

## 질문할 때 지켜 주세요
질문에 고객 이름, 주민등록번호, 연락처, 계약번호 같은 개인정보나 회사 내부 정보를 넣지 마세요. 빠름 모드에서는 질문이 외부(Google)로 전송되고, 무료 등급에서는 보낸 내용이 서비스 개선에 쓰일 수 있어요. 일반적인 문장으로 바꿔서 물어보세요. 예를 들어 "홍길동 고객의 계약이…" 대신 "보험계약자가 보험료를 늦게 내면…"처럼 물어보면 돼요.

## 답변을 읽는 방법
답변은 세 부분으로 나와요.
- 답변 글: 근거를 요약한 설명이에요. 요약이라 틀릴 수 있어요.
- 근거 조문: "풍수해ㆍ지진재해보험법 제7조 p.2" 같은 단추예요. 누르면 답변 바로 아래에 그 조문의 원문이 펼쳐지고, 원문과 대조해 확인된 인용문이 형광펜으로 칠해져 있어요.
- 관련 조문: 점선 단추는 검색에는 걸렸지만 답변에 인용되지 않은 조문이에요. 참고로 직접 확인해 보세요.
답변 아래의 "답변은 요약이에요. 근거는 아래 인용문을 기준으로 확인해 주세요."라는 안내처럼, 업무 판단은 형광펜이 칠해진 원문을 기준으로 해 주세요. "확인된 원문 인용이 없어요" 경고가 붙은 답변은 근거가 확인되지 않은 것이니 관련 조문을 직접 확인해야 해요.

## 원본 문서 보기
근거 조문을 펼친 뒤 "원본 PDF 보기"를 누르면 원본 PDF가 해당 페이지로 열려요. 한글 문서는 "원본 한글 파일 받기"로 내려받을 수 있어요. PC 화면에서는 왼쪽 문서 목록에서 문서나 이전 버전을 눌러도 원본이 열려요.

## 문서 버전과 기준 날짜
같은 문서가 개정되면 관리자가 새 버전(v2, v3)으로 올리고, 이전 버전도 지우지 않고 남겨 둬요. 화면 위쪽의 "최신 버전 기준" 상자에서 날짜를 고르면 그 날짜까지 올라온 버전을 기준으로 답해요. 예전 시점의 규정이 궁금할 때 쓰면 돼요. 답변 근거에는 몇 번째 버전인지(v1, v2) 함께 표시돼요.

## 화면 설정
화면 위쪽의 "백/흑" 단추로 밝은 화면과 어두운 화면을 바꿀 수 있어요. 처음에는 기기 설정을 따르고, 고른 화면은 기억해요. 오른쪽 위 동그란 계정 버튼에서 로그아웃할 수 있어요.

## 질문 기록과 개인정보
누가 언제 무엇을 물었고 어떤 답과 근거가 나갔는지가 증빙을 위해 서버에 기록되고, 관리자가 볼 수 있어요. 그러니 질문에 개인정보를 넣지 마세요.

## 서버에 연결할 수 없을 때
"서버에 연결할 수 없어요"가 나오면 인터넷 연결을 확인하고 "다시 시도"를 눌러요. 그래도 안 되면 서버 노트북이 꺼져 있거나 절전 상태일 수 있으니 관리자에게 알려 주세요.

## 관리자 기능
관리자는 계정 버튼에서 "관리자 화면"으로 들어가 문서 올리기(PDF, 한글 HWP·HWPX, 글 문서 .md), 가입 승인과 거절, 사용자를 관리자로 지정하거나 해제, 질문 기록과 작업 기록 보기, 서버 주소와 답변 모드 설정을 할 수 있어요. 관리자는 여러 명 둘 수 있고, 마지막 관리자는 해제할 수 없어요.

## 문의
가입 승인, 문서 추가 요청, 오류 신고는 관리자에게 해 주세요.
