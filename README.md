# docchat (문서 도우미)

공용 문서(약관·지침 등, 수백 쪽)를 올려 두면 팀원이 대화로 질문하고, **근거 문서·버전·페이지·원문 인용**과 함께 답을 받는 챗봇 앱입니다.
업무가 법적으로 문제없는지 문서로 증명해야 할 때 "문서를 기억하는 친구" 역할을 합니다.

- 최종 정리일: 2026-10-03
- 대상 문서: 인터넷에서 누구나 내려받을 수 있는 공개 문서 (보안·규정 문제 없음 확인)
- 서버: 관리자의 노트북 + 집 공유기로 외부 접속 / 클라이언트: 웹뷰 기반 웹앱

## 폴더 구조
```
C:\work\docchat\
├─ README.md              이 파일 (개요와 목차)
├─ CLAUDE.md              Claude Code용 인수인계 안내서 (작업 규칙, 상태, 다음 작업)
├─ docs\                  설계 문서
│   ├─ 01-requirements.md       요구사항
│   ├─ 02-architecture.md       전체 구조·데이터 모델·검색 방식
│   ├─ 03-ui-design.md          화면 시안과 최종 디자인 결정
│   ├─ 04-auth-flow.md          가입·인증·승인·로그인·비밀번호 초기화
│   ├─ 05-server-api.md         서버 API와 동작 규칙
│   ├─ 06-network-deploy.md     집 공유기·도메인·HTTPS 접속 구성
│   └─ 07-decisions-and-todo.md 결정 기록과 남은 작업
├─ server\                서버 코드 (FastAPI)
└─ mockups\               화면 시안 HTML (브라우저에서 바로 열림)
```

## 현재 상태
| 항목 | 상태 |
|---|---|
| 요구사항·구조 설계 | 완료 |
| 화면 시안 (대화/출처/가입/관리자) | 완료 (확정: A+B+D 통합) |
| 서버 MVP 코드 | 작성 완료, **실제 실행 테스트 전** |
| 웹앱 (시안 → 서버 연동) | 미착수 |
| 외부 접속 (공유기·도메인·HTTPS) | 미착수 |
