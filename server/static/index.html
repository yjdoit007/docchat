같은 이름으로 올리면 새 버전(v2, v3 …)으로 쌓여요. 이전 버전은 지워지지 않아요. PDF와 한글(HWP, HWPX) 파일을 올릴 수 있어요. 한글 문서는 페이지 번호 없이 조문으로 출처를 보여 줘요.

등록된 문서

가입 승인

이메일 인증을 마친 요청만 여기에 나와요.

사용자·관리자

승인된 사용자를 관리자로 지정하거나 해제해요. 관리자는 여러 명 둘 수 있고, 마지막 관리자는 해제할 수 없어요. 지정·해제는 작업 기록에 남아요.

질문 기록

누가 언제 무엇을 물었고, 어떤 답과 출처가 나갔는지 최근 순으로 보여 줘요(최대 200건). 기록은 지우지 않아요.

작업 기록

가입 승인·거절, 관리자 지정·해제, 서버 설정 변경 기록이에요.

답변 모델

팀원이 질문할 때 고를 수 있는 답변 모드와 기본값이에요. 허용한 모드가 둘 이상이면 입력창 위에 선택 버튼이 나와요. 외부 모델(Gemini·Claude)은 질문과 근거 조문이 그 회사로 전송돼요. Gemini 무료 등급은 보낸 내용이 Google 서비스 개선에 쓰일 수 있어요. 외부 모델이 한도·오류로 실패하면 자동으로 로컬 모델로 답해요.
