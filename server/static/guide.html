인증 메일이 안 오면 스팸함을 확인하고, 그래도 없으면 관리자에게 알려 주세요. 비밀번호를 잊으면 로그인 화면의 “비밀번호를 잊으셨나요?”로 바꿀 수 있어요.

답변 읽는 법

정부가 보험료를 얼마나 지원하나요?

국가와 지방자치단체는 예산의 범위에서 보험료의 일부를 지원할 수 있어요. 수급자나 차상위계층이 실제 거주하는 경우 등에는 전부를 지원할 수 있어요.

풍수해ㆍ지진재해보험법 제7조 p.2
제7조(국가 등의 재정지원) ① 국가와 지방자치단체는 예산의 범위에서 보험계약자가 부담하는 보험료의 일부를 지원할 수 있다. 다만, …
시행령 제4조의2 p.1시행령 제4조 p.1
답변은 요약이에요. 근거는 아래 인용문을 기준으로 확인해 주세요. · ⚡ 빠름 (Gemini)로 작성
  • 답변 글근거를 요약한 설명이에요. 요약이라 틀릴 수 있어요.
  • 근거 조문누르면 바로 아래에 원문이 펼쳐져요. 형광펜은 원문과 한 글자씩 대조해 확인된 인용이에요. 업무 판단은 형광펜 원문을 기준으로 해 주세요.
  • 관련 조문점선 단추는 검색에 걸렸지만 인용되지 않은 조문이에요. 필요하면 직접 열어 보세요.
  • 경고가 붙으면“확인된 원문 인용이 없어요”가 보이면 근거가 확인되지 않은 답이에요. 관련 조문을 직접 확인해 주세요.

답변 모드

⚡ 빠름 (Gemini)

보통 2~3초 안에 답해요. 질문과 근거 조문이 Google로 전송돼요.

🔒 내부 (로컬)

이 서버 안에서만 처리해요. 답이 나오기까지 20초 이상 걸려요.

입력창 위에서 고를 수 있고, 고른 모드는 기억해요. 빠름 모드가 응답하지 않으면 자동으로 내부 모드가 답해요.

질문에 개인정보를 넣지 마세요

  • 고객 이름, 주민등록번호, 연락처, 계약번호, 회사 내부 정보는 넣지 않아요.
  • 빠름 모드는 질문이 외부(Google)로 전송되고, 모든 질문은 증빙을 위해 서버에 기록돼요.

사용법은 챗봇에게 바로 물어봐도 돼요. “앱은 어떻게 설치해요?”, “비밀번호를 잊어버렸어요”처럼 물으면 사용 안내를 근거로 답해요. 기준 날짜를 고르면 그 시점의 문서 버전으로 답하고, 근거 조문을 펼친 뒤 “원본 PDF 보기”로 원문도 확인할 수 있어요.

가입 승인 · 문서 추가 요청 · 오류 신고는 관리자에게 해 주세요. 화면 속 답변 예시는 실제 법령 조문을 줄인 것이에요.
